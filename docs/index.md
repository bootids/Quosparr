## Growing the knowledge base

Create focused design decisions, product or gameplay specifications, and execution plans when there is real content to preserve. Keep one owner for each durable fact. Add generated documentation only with a known source and reproducible generator. Do not create databases, services, empty categories, or quality scores merely to fill a template.
